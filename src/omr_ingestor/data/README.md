# MusicXML sound IDs

`sounds.xml` is an unmodified copy of the W3C MusicXML 4.0 sound list,
fetched with curl from:
https://raw.githubusercontent.com/w3c/musicxml/v4.0/schema/sounds.xml

The `sound` elements' `id` attributes define the accepted instrument sound IDs.
The upstream copyright and W3C Community Final Specification Agreement notice
are preserved in the file. To update, fetch the chosen official release and
replace this file, then update this source note and run the instrument tests.
